# 🎣 Advanced Phishing Detection System

A real-time phishing URL detection system built using Python Flask and VirusTotal API.

## 🚀 Features
- Real-time URL scanning
- VirusTotal API integration
- Threat scoring
- Fake domain detection
- URL shortener detection
- Downloadable reports
- Detection history logging

## 🛠 Technologies Used
- Python
- Flask
- HTML/CSS
- Requests Library
- VirusTotal API

## ▶️ Run Project

```bash
pip install flask requests
python app.py
```

Open:
http://127.0.0.1:5001
